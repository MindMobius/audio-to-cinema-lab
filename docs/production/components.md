## 已跑过的局部动画配置

长卷局部动作使用过H3 FL2VA INT8、Turbo 8step LoRA（强度1.0）、8步、`res_multistep` / `simple`，输出832×832；有124帧和243帧的片段，24fps。早期人物资产卡还使用过不同的参考生成工作流与LoRA。两者应按用途区分，不能把参数当成通用默认值。

这些记录能指导复用，但每次执行仍要核对模型文件、节点、输入、端口、显存和实际输出。种子、工作流和哈希提供可追踪性，不保证不同环境像素级复现。耗时随模型加载、长度、显存和并发变化，不作固定承诺。

## 待提炼的通用接口

生成请求应包含：音频区间、视觉目的、资产引用、动作约束、输出规格和工具私有参数。返回应包含：执行状态、实际产物、模型/LoRA/工作流、输入输出哈希、耗时、审查状态与拒绝原因。

作业提交、恢复与选片分开：保留提交id，重连先检查历史，避免重复生成；队列繁忙不能覆盖别人作业；只结束自己启动且已空闲的服务。失败必须可追溯。

合成器接收的是已选资产与时间线。缺镜头直接报缺；重新渲染要核对源哈希；原音轨封装与图像渲染分开。所有记录留在具体作品的本地工程中。
