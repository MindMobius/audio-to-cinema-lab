# 音频驱动 MV 制作手册

本手册提炼自多次本地制作和返修。可复用的是决策方式、图层关系、记录方法和检查方式；某首歌的纸白配色、某个人物或某个模型版本不是所有作品的默认答案。

## 1. 音频是主时轴

登记源文件哈希、音频版本、容器信息、实际解码采样数与时长。NCM 恢复为可播放文件之后再分析；保留原文件和转换回执。不要仅凭文件名认定两个版本相同。

有可靠 LRC 时先保留其入点，抽查人声起点和几个后续段落。前奏没有人声不代表歌词错位。确需调整时记录证据、具体区间、偏移和新版本，不能悄悄全局重排。原文和译文必须成对绑定同一个 cue。

没有可靠文本时才需要识别或对齐；无歌词音乐根据结构、能量、音色和节奏变化建立段落。工具测量与视觉解释分开保存。

剪辑使用整数帧；时间换算要记录取整策略。容器时长、实际音频采样时长和帧量化后的视频时长不是同一个数字。保存完整音轨；若编码格式需要转换，建立一次明确的音频母版，合成后直接封装并验证。

## 2. 先做视觉决策

每个音乐段落明确：听到了什么、情绪如何变化、画面承担什么作用、使用哪些元素、以什么方式承接下一段。不要把节拍检测等同于剪辑，也不要逐字把歌词翻译成写实画面。

在大批量生成前，确定一张主风格参考、色板、线条、材质、人物尺度、留白和禁止项。中段与结尾都引用同一基准；只参考上一个生成结果可能逐步偏离原始方向。

最小样段要暴露风险：角色一致性比较两个镜头；长卷至少经过一个场景接缝；字幕样式比较可以只做5秒。获得明确方向后再扩展全片。常规技术细节自主处理，现有认可不需反复询问。

## 3. 建立资产树

```text
角色身份
  └─ 着装
      └─ 视角（肖像 / 正面 / 侧面 / 背面）
          └─ 姿势或动作参考
场景
  ├─ 构图与尺度
  ├─ 地平线、地面、共享边缘
  ├─ 关键物件
  └─ 文字留白区
```

同一身份和不同服装分开登记。写实、无五官、线稿等都是作品的风格选择。每张卡应包含稳定id、父资产、参考来源、文件哈希、生成方式和选用状态；按镜头需求增加，不先生成大量无用途变体。社区参考需要保留来源与授权信息，仓库许可不替代素材许可。

## 4. 让生成与编排各自承担合适的工作

独立镜头适合由视频生成器承担画面动作；精确运镜、可编辑文字、遮罩、层级和时间关系适合后期控制。

连续长卷已验证的方式：相邻背景共用河岸、地面或建筑元素；背景、局部动画、片头和场景歌词使用同一世界坐标。镜头只移动视窗。局部动画输入裁切区域，保持生成摄像机固定，再用柔边蒙版融入原图。不要用很多互不相关的图片横排来替代连贯世界。

人物脸部在整张宽景中太小时，应以更高像素密度的局部资产生成细节，再嵌回场景；扩大整个世界图不一定解决身份和脸部漂移。局部裁切要足够限定动作，又要保留必要的物件接触关系。生成额外人物、树木或道具时应剔除该条或返修。

连续步行涉及脚底与地面速度匹配，风险高；是否采用应由故事需要决定。长卷可以让不同空间内的故事同时发生，无需让同一个人持续走路。

每条动作默认播放一次。循环、定格和变速可以作为有意的设计，但要登记用途和源区间。缺素材不得自动用静帧、循环或等长分段填满歌曲。

## 5. 两种字幕与片头方式

| 模式 | 适用场景 | 规则 |
| --- | --- | --- |
| 简洁电影双语字幕 | 分镜切换、较丰富的画面 | 屏幕底部，原文与中文同步，保证边距和字号 |
| 场景歌词 | 长卷或稳定空间构图 | 歌词固定在世界坐标，整组提前可读，当前行有清晰标记，唱完渐隐 |

已确认的长卷参考样式：原文行两侧手绘短中括号，中文在下方；当前行不变色、不放大；换句括号约1/6秒过渡，唱完的双语行约0.75秒淡出。这些值是参考，应按目标帧率量化并检查，不是普适标准。

文字由编辑器生成，不烘焙进AI图像。审查时既看文字可读性，也看它是否抢走所有注意力、是否被镜头过早移出、是否遮挡人物和相邻歌词。

歌名使用确认名称，创作署名核对来源；不擅自增加译名。需要首帧片头时，第一帧即出现。连续长卷的开场属于同一个世界，镜头从首帧移动；和正文连接时同时匹配位置与速度。面向中文社区的说明与制作署名优先中文，模型和工具保留正式名称。

## 6. 选片、验收、交付

先对照计划核对每段实际使用的素材：生成成功、进入成片、画面合格是三种不同状态。选片表应记录源哈希、使用区间、返修版本、是否循环及原因；旧缓存必须验证输入哈希。

技术检查包含：解码、帧数、时长、字幕边界、资源引用、音轨比对、开头和结尾、镜头是否反向或跳动。黑帧检测需要符合作品色调；不能把纸白作品的亮度阈值套用到暗调MV。全帧变化也不能证明人物在动，摄影机移动本身就会改变画面。

视觉审查包含：画风一致、脸部和手部、动作连贯、场景接缝、物件接触、构图留白、歌词阅读与音乐情绪。记录实际审查的时段和方法；抽帧检查不能写成全片实时观看。

成片、封面、制作说明、必要字幕副本与校验记录共同交付。保留旧版，当前选用版本要有唯一入口。只改歌词、片头或摄影机时，复用已选素材并重做受影响的合成与检查。
