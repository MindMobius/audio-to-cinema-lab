# Audio-driven video

This pipeline starts with an audio master and ends with a verified composition.

1. register source audio;
2. run text or music analysis;
3. write a creative plan;
4. register required assets;
5. generate and review shots;
6. assemble an integer-frame edit;
7. add captions and title information;
8. render and verify.

The lyric MV pipeline is one specialization. Instrumental and voiceover projects can use the same artifact contracts with different analysis adapters.
