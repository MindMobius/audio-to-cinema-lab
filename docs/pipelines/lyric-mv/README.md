# 歌词音乐视频

先登记音频母版与歌词来源。用户确认匹配的 LRC 是时间轴依据；器乐前奏不意味着歌词错位，不应因此擅自整体平移。没有可靠时间轴时，再使用转写或强制对齐，保留验证依据。

原文与译文共享同一 cue 的起止时间。翻译作为创作资产单独审查，不混入时间轴修正。字幕采用屏幕底部或场景坐标，由视觉方案选择；图像生成与文字排版分层处理。

完整作品只存于忽略的本地工程目录，包括歌词、字幕、分镜、提示词、工作流与检查记录。公共仓库只保留通用契约、空白模板、制作方法和合成测试数据。
