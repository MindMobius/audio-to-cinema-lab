# 音乐资产库与工程入口统一 — 2026-11-11

用户要求把已讨论的结构和音乐管理全部落地。此决策取代先前把新工程放在 `.local/projects/` 的目录选择，继续执行具体作品不进入 Git 的要求。

- `source/music/` 保留用户原始音频与歌词。
- `library/music/` 管理稳定的音源身份、按需准备、缓存校验、歌词版本和处理回执。
- `projects/YYYY-MM-DD/<slug>/` 是唯一日常工程入口，工程固定选用版本。
- `archive/` 保留迁移原件。先复制校验，再归档原件并删除旧工作目录；不建立兼容链接。
- 共享缓存按音源和输出哈希管理，不按歌曲显示名覆盖。
- 旧工程仅在音频字节匹配时自动关联，不能把同名歌曲不同音源视为同一版本。
- 分析与创意分离；本轮不宣称实现自动 ASR、音乐结构分析或全自动 MV 生成。
- Git 只发布 Lab 的通用实现、模板、文档与合成测试。

## 彻底移除旧路径

所有活动脚本、清单和配置使用规范目录；完成引用改写与校验后删除旧目录和兼容链接。归档只保存迁移证据，不是运行入口。迁移命令同时处理仍有实体数据的旧目录和已经复制完毕但遗留链接的情况。项目媒体清单只接受 `media/` 或 `audio/` 作为恢复目标。
