## What is in Git

The repository keeps the creative plan, audio observations, asset provenance, selected previews, ComfyUI workflow graphs, edit timeline, HyperFrames opening source and verification summary.

## What stays private-local

The source recording, complete lyric text and translations, full generated video clips, model files, ComfyUI runtime state and machine-specific caches are intentionally omitted. This keeps the public repository smaller and avoids publishing user-supplied copyrighted material. `project.json` and the manifests preserve hashes and restoration hints.

## Production source

The complete working project is retained at `${LOCAL_PROJECT_ROOT}/one-last-kiss-mv-20261108` on the producing machine. The public project is a documented migration, not a replacement for that private media workspace.
